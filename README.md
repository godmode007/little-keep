# Little Keep

A **simple single-player** castle game: D&D for a mixed-age table (about 6–14). Inspired by Kingshot’s build → gather → recruit → quest loop.

This is separate from **Dragonhold** (the deeper D&D strategy project). Both live side by side.

## For a mixed-age table

- Short sessions, offline, no chat / no multiplayer
- Party of a knight, a wood elf, a fairy, and an elf cleric
- Trolls and ogres to shoo — never slay
- Soft colors, big buttons, clear star goals

## Play

```bash
cd little-keep
npm install
npx expo start
```

Use Expo Go on a phone, or press `w` for web.

## Loop

1. **Home** — Collect food & wood on the keep field, clear misty woods for watch towers  
2. **Build** — Upgrade Castle, Farm, Forest Hut, Workshop, Watch Tower  
3. **Friends** — Recruit Pip, Mira, Blink, Nana  
4. **Quests** — Finish adventures when your party is strong enough  

See `GAME_DESIGN.md` for the full kid-friendly design notes.
